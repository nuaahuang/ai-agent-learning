## 一、L3 概览：为什么需要高级推理算法？

到目前为止，你的 Agent 是**线性推理**的：

```text
Thought 1 → Action 1 → Observation 1 → Thought 2 → Action 2 → ...
```

**问题**：
1. **一条路走到黑**：如果第一步就错了，后面全错
2. **没有探索**：不会考虑多种可能性
3. **没有回溯**：错了不会回头重新选择

**L3 要解决的问题**：

| 算法 | 核心思想 | 解决的问题 |
|------|---------|-----------|
| **Tree of Thoughts (ToT)** | 同时探索多条推理路径 | 复杂规划问题 |
| **Graph of Thoughts (GoT)** | 推理路径可以合并/分支 | 创造性问题 |
| **Monte Carlo Tree Search (MCTS)** | 随机探索 + 反向传播 | 博弈/决策问题 |

## 二、L3-01：Tree of Thoughts（ToT）

### 核心思想

```text
传统 ReAct（一条直线）：
问题 → 思考 → 行动 → 观察 → 思考 → 行动 → 观察 → 答案

Tree of Thoughts（多路径探索）：
问题
├── 方案 A → 行动 A1 → 观察 A1 → 继续
│   ├── 方案 A1 → ...
│   └── 方案 A2 → ...
├── 方案 B → 行动 B1 → 观察 B1 → 继续
│   ├── 方案 B1 → ...
│   └── 方案 B2 → ...
└── 方案 C → 行动 C1 → 观察 C1 → 继续
    └── 方案 C1 → ...
```

### 关键概念

1. **节点（Node）**：一个推理状态（Thought + Action + Observation）
2. **分支（Branch）**：一个可能的推理路径
3. **评估（Evaluate）**：给每个分支打分
4. **剪枝（Prune）**：删除低分分支
5. **回溯（Backtrack）**：回到上一个决策点

## 四、ToT 的核心流程

```text
1. 生成多个思考方向（Branching）
   ↓
2. 评估每个方向（Evaluation）
   ↓
3. 选择 Top-K 分支（Selection）
   ↓
4. 对每个分支执行行动（Action）
   ↓
5. 递归到下一层（Recursion）
   ↓
6. 到达最大深度后选择最优路径（Selection）
   ↓
7. 生成最终答案（Answer）
```

---

## 五、ToT vs ReAct

| 特性 | ReAct | Tree of Thoughts |
|-----|-------|-----------------|
| **推理路径** | 一条直线 | 多路径树 |
| **探索能力** | 弱 | 强 |
| **容错能力** | 低（一步错步步错） | 高（可以回溯） |
| **计算成本** | 低 | 高（多分支） |
| **适用场景** | 简单问题 | 复杂规划问题 |
