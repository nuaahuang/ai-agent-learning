# L6-01: Token 预算与熔断

## 1. 核心概念

### 1.1 Token 预算定义

Token 预算管理是指对大模型 API 调用的 Token 使用进行精细化控制，包括：

- **成本控制**：限制每日/每月的 Token 消耗量
- **资源分配**：不同Agent/用户分配不同的 Token 额度
- **使用追踪**：实时监控 Token 消耗情况
- **超额熔断**：超出预算时自动熔断

### 1.2 为什么需要 Token 预算

| 问题 | 影响 |
|------|------|
| **成本失控** | 无限制调用导致费用飙升 |
| **资源浪费** | 低效调用消耗大量 Token |
| **公平性** | 个别用户占用过多资源 |
| **风险控制** | 异常调用导致巨额账单 |

## 3. 核心功能

### 3.1 预算类型

| 预算类型 | 说明 | 示例 |
|---------|------|------|
| **全局预算** | 整个系统的总预算 | 每日 100万 Token |
| **Agent预算** | 每个Agent的独立预算 | AgentA 每日 10万 Token |
| **用户预算** | 每个用户的配额 | 用户X 每日 5万 Token |
| **单次预算** | 单次调用的最大Token | 单次最多 4096 Token |

### 3.2 计费维度

- **输入 Token**：Prompt 消耗的 Token
- **输出 Token**：Completion 消耗的 Token
- **总 Token**：输入 + 输出

### 3.3 熔断策略

| 策略 | 说明 |
|------|------|
| **硬熔断** | 达到限额直接拒绝 |
| **软熔断** | 达到限额发出警告，允许少量超额 |
| **阶梯熔断** | 不同阶段有不同限制 |

---

## 4. 关键指标

### 4.1 使用率指标

```
使用率 = 已消耗 / 总预算 × 100%
```

### 4.2 告警阈值

- **80%**：黄色预警
- **90%**：橙色预警
- **100%**：红色熔断

---

## 5. 实践要点

### 5.1 预算周期

- 按天重置
- 按月重置
- 滑动窗口

### 5.2 Token 估算

- 精确统计：调用后获取实际 Token 数
- 预估算：调用前估算 Token 数量
- 混合模式：预估算 + 精确统计

### 5.3 持久化

- 内存存储（单机）
- Redis（分布式）
- 数据库（持久化审计）

---

## 6. 总结

Token 预算与熔断是规模化应用的必备能力：
- 有效控制成本
- 保障系统公平性
- 防止异常消耗
- 提供预算可视化
