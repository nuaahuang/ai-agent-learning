# L7-03: 垂直领域 Agent（Domain-Specific Agent）

## 1. 核心概念

### 1.1 什么是垂直领域 Agent

垂直领域 Agent 是针对特定行业/专业领域深度定制的智能体，相比通用 Agent 具备更强的领域专业性：

- **通用 Agent**：什么都能聊，但不够专业
- **垂直 Agent**：聚焦特定领域，专业、精准、可靠

### 1.2 通用 vs 垂直

| 维度 | 通用 Agent | 垂直 Agent |
|------|-----------|-----------|
| 知识广度 | 广 | 窄但深 |
| 专业术语 | 一般 | 精准 |
| 工具集成 | 通用工具 | 领域专用工具 |
| 合规要求 | 低 | 高（金融/医疗） |
| 准确性要求 | 中 | 极高 |

### 1.3 典型垂直领域

| 领域 | 应用 | 特殊要求 |
|------|------|---------|
| **金融** | 投研分析、风控、量化 | 合规、实时、精准 |
| **医疗** | 辅助诊断、病历分析 | 安全、可解释、责任 |
| **法律** | 合同审查、案例检索 | 严谨、引用准确 |
| **教育** | 个性化辅导、批改 | 适龄、循循善诱 |
| **游戏** | NPC、对战AI | 实时、策略 |

## 2. 垂直 Agent 的构建要素

### 2.1 五大构建要素

```
┌─────────────────────────────────────────────────────────┐
│                  垂直领域 Agent                          │
├─────────────────────────────────────────────────────────┤
│  ① 领域知识库   (RAG / 微调 / 知识图谱)                 │
│  ② 专业工具集   (领域API、计算工具、数据源)             │
│  ③ 领域提示词   (角色设定、专业约束、输出规范)          │
│  ④ 合规护栏     (行业规范、免责声明、风险控制)          │
│  ⑤ 评估体系     (领域专家评估、专业指标)                │
└─────────────────────────────────────────────────────────┘
```

### 2.2 知识注入方式

| 方式 | 适用 | 特点 |
|------|------|------|
| **RAG检索** | 知识频繁更新（如政策法规） | 实时、可溯源 |
| **微调** | 固定专业能力（如术语、风格） | 内化、稳定 |
| **知识图谱** | 结构化关系（如药物相互作用） | 精准、可推理 |
| **工具调用** | 实时数据（如股价、检验值） | 准确、动态 |

## 3. 领域案例分析

### 3.1 金融分析 Agent

| 能力 | 实现 |
|------|------|
| 财报分析 | 解析财务数据 + 计算指标 |
| 行情查询 | 实时行情API |
| 风险评估 | 风控模型 + 规则 |
| 投研报告 | 数据整合 + 生成 |

**特殊要求**：合规免责声明、不构成投资建议、数据实时性。

### 3.2 医疗诊断 Agent

| 能力 | 实现 |
|------|------|
| 症状分析 | 医学知识库 + 推理 |
| 检验解读 | 检验值参考范围对照 |
| 用药建议 | 药物数据库 + 相互作用检查 |
| 辅助诊断 | 鉴别诊断推理 |

**特殊要求**：仅供参考、建议就医、可解释、责任边界。

### 3.3 游戏 AI Agent

| 能力 | 实现 |
|------|------|
| NPC对话 | 角色人设 + 对话生成 |
| 策略决策 | 博弈树 / 强化学习 |
| 难度调节 | 动态平衡 |
| 行为规划 | 行为树 / 状态机 |

**特殊要求**：实时响应、可玩性、难度平衡。

## 4. 工程实践

### 4.1 领域 Agent 设计模式

| 模式 | 说明 |
|------|------|
| **路由分发** | 根据问题类型路由到专业子Agent |
| **专家协作** | 多个领域专家Agent协作（结合L4） |
| **人工兜底** | 高风险决策人工介入（结合L6-04） |
| **可解释** | 输出推理依据和数据来源 |

### 4.2 关键工程点

| 要点 | 说明 |
|------|------|
| **数据时效性** | 领域数据需及时更新 |
| **专业校验** | 输出经领域规则校验 |
| **免责合规** | 高风险领域必须声明 |
| **引用溯源** | 给出知识来源，可验证 |
| **置信度** | 低置信度时提示不确定性 |

### 4.3 与通用能力结合

垂直 Agent 是前面所有能力的综合应用：
- **L2 ReAct**：推理+工具调用
- **L3 高级推理**：复杂决策
- **L4 多Agent**：领域专家协作
- **L5 工程化**：可靠运行
- **L6 稳定性**：限流、护栏、人工介入
- **L7 领域深化**：微调、多模态、领域知识

---

## 5. 总结

垂直领域 Agent 是 Agent 落地的关键形态：
- 聚焦特定领域，追求专业、精准、可靠
- 核心要素：领域知识、专业工具、领域提示词、合规护栏、评估体系
- 知识注入：RAG、微调、知识图谱、工具调用各有适用
- 高风险领域（金融/医疗）需特别关注合规与人工兜底
- 是 L1-L7 所有能力的综合实战
