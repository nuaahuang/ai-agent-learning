# L8-01: Agent 记忆存储（Memory）

## 1. 核心概念

### 1.1 为什么 Agent 需要记忆

大模型本身是"无状态"的——每次调用都是独立的，不记得之前的对话。记忆系统让 Agent 能够：

- **保持上下文连贯**：记住多轮对话
- **积累长期知识**：跨会话记住用户偏好、事实
- **从经验学习**：记住成功/失败的经验
- **个性化**：根据历史交互定制响应

### 1.2 记忆的分类

| 类型 | 类比 | 说明 | 存储时长 |
|------|------|------|---------|
| **短期记忆** | 工作记忆 | 当前对话上下文 | 会话内 |
| **长期记忆** | 长期记忆 | 跨会话持久化 | 永久 |
| **情景记忆** | 经历回忆 | 具体事件/交互记录 | 长期 |
| **语义记忆** | 知识概念 | 事实、概念、规则 | 长期 |
| **程序记忆** | 技能习惯 | 操作流程、技能 | 长期 |

## 2. 记忆架构

### 2.1 分层记忆架构

```
┌─────────────────────────────────────────────────────────────┐
│                     Agent Memory System                    │
├─────────────────────────────────────────────────────────────┤
│                                                            │
│   ┌──────────────────┐         ┌──────────────────┐        │
│   │   短期记忆        │         │   长期记忆        │        │
│   │  (上下文窗口)     │ ←─────→ │  (持久化存储)     │        │
│   │  - 当前对话       │  提取   │  - 向量数据库     │        │
│   │  - 最近N轮        │  归档   │  - 知识图谱       │        │
│   └──────────────────┘         │  - 关系数据库     │        │
│           │                    └──────────────────┘        │
│           │ 超出窗口                     │                  │
│           ▼                              ▼                  │
│   ┌──────────────────┐         ┌──────────────────┐        │
│   │   记忆压缩        │         │   记忆检索        │        │
│   │  (摘要/淘汰)      │         │  (语义/时间)      │        │
│   └──────────────────┘         └──────────────────┘        │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 短期记忆管理策略

| 策略 | 说明 | 适用 |
|------|------|------|
| **全量保留** | 保留所有历史 | 短对话 |
| **滑动窗口** | 只保留最近N轮 | 长对话 |
| **摘要压缩** | 旧对话压缩成摘要 | 超长对话 |
| **重要性筛选** | 保留关键信息 | token受限 |

### 2.3 长期记忆的存储

| 存储 | 适用 | 特点 |
|------|------|------|
| **向量数据库** | 语义检索（Chroma/Milvus/Pinecone） | 相似度搜索 |
| **关系数据库** | 结构化事实 | 精确查询 |
| **知识图谱** | 实体关系 | 关系推理 |
| **文档存储** | 原始记录 | 完整保留 |

## 3. 记忆的关键操作

### 3.1 记忆生命周期

```
写入(Encode) → 存储(Store) → 检索(Retrieve) → 更新(Update) → 遗忘(Forget)
```

| 操作 | 说明 |
|------|------|
| **写入** | 从对话中提取值得记住的信息 |
| **存储** | 持久化到合适的存储后端 |
| **检索** | 根据当前需要召回相关记忆 |
| **更新** | 修正、合并、强化已有记忆 |
| **遗忘** | 淘汰过期、不重要的记忆 |

### 3.2 记忆写入：提取什么？

- **用户画像**：偏好、习惯、身份信息
- **关键事实**：明确陈述的事实
- **任务状态**：进行中的任务和进度
- **交互经验**：成功/失败的方法

### 3.3 记忆检索：如何召回？

| 检索方式 | 说明 |
|---------|------|
| **语义检索** | 向量相似度，召回语义相关记忆 |
| **时间检索** | 按时间近远（最近优先） |
| **重要性** | 按重要性评分 |
| **混合检索** | 语义+时间+重要性加权 |

> MemGPT、Mem0 等框架的核心思想：用"重要性 + 时效性 + 相关性"综合打分召回。

## 5. 工程实践

### 5.1 记忆与上下文窗口

```
对话不断增长 → 超出上下文窗口 → 必须管理记忆
解决: 滑动窗口 + 摘要压缩 + 长期记忆归档
```

### 5.2 关键工程点

| 要点 | 说明 |
|------|------|
| **token预算** | 记忆占用token，需与L6 token预算结合 |
| **检索质量** | 召回不准会引入噪声，影响回答 |
| **隐私安全** | 记忆含隐私，需脱敏（结合L6护栏） |
| **记忆冲突** | 新旧记忆矛盾时的处理策略 |
| **遗忘机制** | 避免记忆无限增长 |

### 5.3 与其他模块的关系

- **L5-02 Checkpoint**：记忆持久化的存储基础
- **L8-02 RAG**：长期记忆检索本质是 RAG
- **L6 护栏**：记忆写入/读取需脱敏

---

## 6. 总结

Agent 记忆系统是实现"有状态、个性化、持续学习"的关键：
- 短期记忆管上下文连贯，长期记忆管跨会话积累
- 核心操作：写入→存储→检索→更新→遗忘
- 长期记忆检索本质是向量检索（与RAG同源）
- 工程上需关注 token 预算、检索质量、隐私、遗忘机制
